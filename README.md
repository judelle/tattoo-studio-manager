# Tattoo Studio Manager

Внутренняя система управления тату-студией, написанная на Go.

Проект создается как реальный рабочий инструмент для управления клиентами и записями тату-студии.

На первом этапе приложение разрабатывается в виде консольной программы с локальным хранением данных. В дальнейшем планируется адаптация под Telegram-бота, подключение PostgreSQL и развертывание на сервере.

## Основной функционал

- добавление и хранение клиентов;
- поиск и редактирование клиентов;
- создание записей на сеансы;
- просмотр расписания на выбранную дату;
- перенос записей;
- отмена и завершение записей;
- хранение плановой и фактической стоимости;
- учет предоплаты;
- хранение нескольких эскизов для одной записи;
- просмотр истории записей клиента.

## Технологии

- Go
- JSON
- Telegram Bot API
- PostgreSQL
- Docker
